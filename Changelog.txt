fastebaysearch 0.6.0

- Refactored all code to make it easier to maintain.
- Reworked result claiming and notification flow. New results are now claimed in SQLite before notifications are sent, preventing duplicate notification races.
- Added per-channel notification retry state for email and Telegram.
- Improved SQLite locking and schema handling with BEGIN IMMEDIATE locks, idempotent schema creation and safer history run tracking.
- Added exchange rate caching to SQLite with configurable TTL.
- Improved eBay API robustness, token response validation and aiohttp session reuse.
- Added api_concurrency, telegram_send_mode and stricter config validation.
- Improved SMTP handling with proper STARTTLS SSL context and optional authentication.
- Made OAuth token cache writes atomic and tightened token file permissions where supported.
- Improved query generation, config path handling and database path restrictions.
- Improved date parsing performance with from iso format fallback logic.
- Reduced broad exception handling and replaced several generic catch blocks with specific exception types.
- Made email and Telegram notifiers return success status and injectable for tests.
- Added tests for notification retry behavior, history updates, config validation and notifier injection.
- Added pytest.ini and .gitignore rules to keep pytest temp/cache directories out of test collection and version control.
- Removed obsolete legacy database migration support and unused legacy conversion code.
